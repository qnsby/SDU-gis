# План разработки сайта для студента университета

## Основные компоненты:
1. **src/App.tsx** - обновить роутинг для новых страниц
2. **src/pages/Index.tsx** - главная страница с навигацией
3. **src/pages/Rooms.tsx** - страница свободных кабинетов
4. **src/pages/Events.tsx** - страница актуальных событий
5. **src/pages/CampusMap.tsx** - страница с картой кампуса
6. **src/components/Navigation.tsx** - компонент навигации
7. **src/components/RoomCard.tsx** - карточка кабинета
8. **src/components/EventCard.tsx** - карточка события

## Функциональность:
- Главная страница с обзором и быстрым доступом к разделам
- Страница свободных кабинетов с фильтрацией и поиском
- Страница событий с календарем и деталями мероприятий
- Интерактивная карта кампуса с отмеченными зданиями
- Адаптивный дизайн для мобильных устройств
- Современный UI с использованием shadcn/ui компонентов
